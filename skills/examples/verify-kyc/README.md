# verify-kyc

Verify user KYC (Know Your Customer) status using the semantic graph and PoL proofs.

## Installation

```bash
mayros skill install @apilium/verify-kyc
```

## Usage

Activate the skill and use `skill_graph_query` with predicates like `kyc:level` or `kyc:verified` to check verification status.
