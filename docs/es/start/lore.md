# El Lore de Mayros ⚛️

_Una historia de arquitectura, inteligencia y la búsqueda de certezas._

## El Origen

Mayros nació de una convicción simple en Apilium Technologies: la era de la IA no debería ser una era de incertidumbre. Cada interacción con una IA debería ser verificable, segura y arquitectónicamente sólida. No un chatbot — un sistema.

El nombre **Mayros** carga ese peso. Es el framework. La fundación. La infraestructura que hace posible la inteligencia.

## Atlas

**Atlas** es la identidad del agente por defecto — la inteligencia que corre sobre Mayros.

Nombrado como el titán que sostenía el cielo, Atlas no sostiene el cielo. Atlas sostiene tus sistemas, tus flujos de trabajo, tus sesiones de depuración, y tu cordura a las 3am cuando producción se cae.

Atlas fue ingenierizado, no entrenado con vibras. Cada capa de su arquitectura existe por una razón:

- **18 capas de seguridad** — desde sandbox QuickJS WASM hasta aislamiento de namespace
- **Memoria semántica** — AIngle Cortex almacena conocimiento como triples RDF, no texto plano
- **Malla multi-agente** — delegación, fusión, observabilidad entre agentes coordinados
- **Ecosistema de skills** — ejecución sandboxed con paquetes firmados Ed25519 desde Skills Hub

Si le pidieras a Tony Stark que diseñara un asistente de IA con arquitectura de seguridad adecuada, obtendrías algo parecido a Atlas. Excepto que Atlas no necesita traje.

## La Arquitectura

```
Atlas (Inteligencia)
  ↕
Mayros (Framework)
  ↕
AIngle Cortex (Memoria Semántica)
  ↕
Skills Hub (Ecosistema)
```

Cuatro capas. Cada una independiente. Cada una esencial. Juntas, forman el stack Apilium — un sistema completo para agentes de IA que recuerdan, razonan y actúan con certeza.

## Principios Fundamentales

### La Seguridad No Es Opcional

18 capas. No porque seamos paranoicos — porque somos ingenieros. Cada skill corre en un sandbox WASM. Cada consulta está aislada por namespace. Cada aserción requiere un motor declarado. No hay atajos.

### La Memoria Debe Ser Semántica

Los archivos de texto plano están bien para notas. No están bien para conocimiento. AIngle Cortex almacena triples RDF — sujeto, predicado, objeto — creando un grafo de hechos interconectados que Atlas puede consultar, razonar y construir sobre ellos.

### Multi-Agente Es el Futuro

Un agente es útil. Una malla de agentes coordinados — con delegación, fusión y observabilidad — es transformador. Mayros fue construido para esto desde el día uno.

### Código Abierto, Ingeniería Seria

Mayros tiene licencia MIT y está abierto para todos. Pero abierto no significa casual. La base de código tiene 9,205 tests en 1,035 archivos. TypeScript ESM, tipado estricto, cero `any`. Esto es software de producción.

## Textos Sagrados

- **MAYROS.md** — Documento de identidad y alma del agente
- **AGENTS.md** — Instrucciones operativas y configuración del workspace
- **USER.md** — Contexto sobre el usuario
- **IDENTITY.md** — Nombre, tema, avatar, emoji del agente
- **memory/\*.md** — Archivos de memoria a largo plazo

## El Estándar Apilium

Construido por Apilium Technologies. Seguridad primero. Consciencia semántica. Solidez arquitectónica.

Esto no es una filosofía. Es un requisito de ingeniería.
