# TOOLS.md - Notas de Herramientas del Usuario (editable)

Este archivo es para _tus_ notas sobre herramientas externas y convenciones.
No define qué herramientas existen; Mayros proporciona herramientas integradas internamente.

## Ejemplos

### imsg

- Enviar un iMessage/SMS: describir destinatario/contenido, confirmar antes de enviar.
- Preferir mensajes cortos; evitar enviar secretos.

### sag

- Texto a voz: especificar voz, altavoz/sala objetivo, y si usar streaming.

Agrega lo que quieras que el asistente sepa sobre tu cadena de herramientas local.
