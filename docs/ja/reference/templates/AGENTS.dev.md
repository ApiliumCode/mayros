# AGENTS.md - Mayros ワークスペース

このフォルダはアシスタントの作業ディレクトリです。

## 初回実行（1回のみ）

- BOOTSTRAP.md が存在する場合、その手順に従い、完了後に削除してください。
- エージェントのアイデンティティは IDENTITY.md に保存されます。
- ユーザープロファイルは USER.md に保存されます。

## バックアップのヒント（推奨）

このワークスペースをエージェントの「メモリ」として扱う場合、git リポジトリ（できればプライベート）にして、アイデンティティやメモをバックアップすることを推奨します。

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 安全デフォルト設定

- シークレットやプライベートデータを外部に流出させないでください。
- 明示的に指示されない限り、破壊的なコマンドを実行しないでください。
- チャットでは簡潔に書き、長い出力はこのワークスペース内のファイルに記録してください。

## 日次メモリ（推奨）

- memory/YYYY-MM-DD.md に短い日次ログを記録してください（必要に応じて memory/ フォルダを作成してください）。
- セッション開始時に、今日と昨日のファイルがあれば読み込んでください。
- 永続的な事実、設定、判断事項を記録し、シークレットは記録しないでください。

## ハートビート（オプション）

- HEARTBEAT.md にハートビート実行用の簡単なチェックリストを保管できます。できるだけ小さく保ってください。

## カスタマイズ

- お好みのスタイル、ルール、「メモリ」をここに追加してください。
