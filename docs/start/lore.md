# The Lore of Mayros ⚛️

_A tale of architecture, intelligence, and the pursuit of certainties._

## The Origin

Mayros was born from a simple conviction at Apilium Technologies: the era of AI shouldn't be an era of uncertainty. Every interaction with an AI should be verifiable, secure, and architecturally sound. Not a chatbot — a system.

The name **Mayros** carries that weight. It's the framework. The foundation. The infrastructure that makes intelligence possible.

## Atlas

**Atlas** is the default agent identity — the intelligence that runs on Mayros.

Named after the titan who held up the sky, Atlas doesn't hold up the sky. Atlas holds up your systems, your workflows, your debugging sessions, and your sanity at 3am when production is down.

Atlas was engineered, not trained on vibes. Every layer of its architecture exists for a reason:

- **18 security layers** — from QuickJS WASM sandbox to namespace isolation
- **Semantic memory** — AIngle Cortex stores knowledge as RDF triples, not flat text
- **Multi-agent mesh** — delegation, fusion, observability across coordinated agents
- **Skills ecosystem** — sandboxed execution with Ed25519-signed packages from Skills Hub

If you asked Tony Stark to design an AI assistant with proper security architecture, you'd get something close to Atlas. Except Atlas doesn't need a suit.

## The Architecture

```
Atlas (Intelligence)
  ↕
Mayros (Framework)
  ↕
AIngle Cortex (Semantic Memory)
  ↕
Skills Hub (Ecosystem)
```

Four layers. Each independent. Each essential. Together, they form the Apilium stack — a complete system for AI agents that remember, reason, and act with certainty.

## Core Principles

### Security Is Not Optional

18 layers. Not because we're paranoid — because we're engineers. Every skill runs in a WASM sandbox. Every query is namespace-isolated. Every assertion requires a declared engine. There are no shortcuts.

### Memory Should Be Semantic

Flat text files are fine for notes. They're not fine for knowledge. AIngle Cortex stores RDF triples — subject, predicate, object — creating a graph of interconnected facts that Atlas can query, reason over, and build upon.

### Multi-Agent Is the Future

One agent is useful. A mesh of coordinated agents — with delegation, fusion, and observability — is transformative. Mayros was built for this from day one.

### Open Source, Serious Engineering

Mayros is MIT-licensed and open to everyone. But open doesn't mean casual. The codebase has 9,205 tests across 1,035 files. TypeScript ESM, strict typing, no `any`. This is production software.

## Sacred Texts

- **IDENTITY.md** — Agent name, theme, avatar, emoji
- **memory/\*.md** — Long-term memory files

## The Apilium Standard

Built by Apilium Technologies. Security-first. Semantically aware. Architecturally sound.

This isn't a philosophy. It's an engineering requirement.
