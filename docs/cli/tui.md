# `mayros tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
mayros tui
mayros tui --url ws://127.0.0.1:18789 --token <token>
mayros tui --session main --deliver
```
