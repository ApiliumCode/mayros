# `mayros setup`

Initialize `~/.mayros/mayros.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
mayros setup
mayros setup --workspace ~/.mayros/workspace
```

To run the wizard via setup:

```bash
mayros setup --wizard
```
