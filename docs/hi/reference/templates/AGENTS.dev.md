# AGENTS.md - Mayros वर्कस्पेस

यह फ़ोल्डर असिस्टेंट की कार्य निर्देशिका है।

## पहली बार चलाना (एक बार)

- यदि BOOTSTRAP.md मौजूद है, तो उसकी प्रक्रिया का पालन करें और पूरा होने पर उसे हटा दें।
- आपकी एजेंट आइडेंटिटी IDENTITY.md में संग्रहीत है।
- आपकी प्रोफ़ाइल USER.md में संग्रहीत है।

## बैकअप सुझाव (अनुशंसित)

यदि आप इस वर्कस्पेस को एजेंट की "मेमोरी" के रूप में उपयोग करते हैं, तो इसे एक git रिपॉज़िटरी (अधिमानतः प्राइवेट) बनाएं ताकि आइडेंटिटी और नोट्स का बैकअप हो सके।

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## सुरक्षा डिफ़ॉल्ट

- सीक्रेट्स या निजी डेटा को बाहर न भेजें।
- स्पष्ट रूप से अनुरोध किए जाने तक विनाशकारी कमांड न चलाएं।
- चैट में संक्षिप्त रहें; लंबा आउटपुट इस वर्कस्पेस की फ़ाइलों में लिखें।

## दैनिक मेमोरी (अनुशंसित)

- memory/YYYY-MM-DD.md में एक संक्षिप्त दैनिक लॉग रखें (आवश्यकता हो तो memory/ फ़ोल्डर बनाएं)।
- सत्र शुरू होने पर आज और कल की फ़ाइल मौजूद हो तो पढ़ें।
- स्थायी तथ्य, प्राथमिकताएं और निर्णय दर्ज करें; सीक्रेट्स दर्ज न करें।

## हार्टबीट (वैकल्पिक)

- HEARTBEAT.md में हार्टबीट रन के लिए एक छोटी चेकलिस्ट रख सकते हैं; इसे छोटा रखें।
