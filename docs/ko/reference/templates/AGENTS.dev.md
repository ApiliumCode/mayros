# AGENTS.md - Mayros 워크스페이스

이 폴더는 어시스턴트의 작업 디렉터리입니다.

## 최초 실행 (1회)

- BOOTSTRAP.md가 존재하면 해당 절차를 따르고, 완료 후 삭제하세요.
- 에이전트 아이덴티티는 IDENTITY.md에 저장됩니다.
- 사용자 프로필은 USER.md에 저장됩니다.

## 백업 팁 (권장)

이 워크스페이스를 에이전트의 "메모리"로 활용한다면 git 저장소(가급적 프라이빗)로 만들어 아이덴티티와 메모를 백업하는 것을 권장합니다.

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 안전 기본 설정

- 시크릿이나 개인 데이터를 외부로 유출하지 마세요.
- 명시적으로 요청하지 않는 한 파괴적인 명령을 실행하지 마세요.
- 채팅에서는 간결하게 작성하고, 긴 출력은 이 워크스페이스 내 파일에 기록하세요.

- 세션 시작 시 오늘과 어제 파일이 있으면 읽으세요.
- 지속적인 사실, 선호 사항, 결정 사항을 기록하고 시크릿은 기록하지 마세요.
