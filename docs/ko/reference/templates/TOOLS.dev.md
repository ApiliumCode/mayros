# TOOLS.md - 사용자 도구 메모 (편집 가능)

이 파일은 외부 도구 및 관례에 대한 _사용자_ 메모용입니다.
어떤 도구가 존재하는지 정의하지 않습니다. Mayros는 내장 도구를 내부적으로 제공합니다.

## 예시

### imsg

- iMessage/SMS 보내기: 수신인과 내용을 설명하고, 보내기 전에 확인하세요.
- 짧은 메시지를 선호하며, 시크릿은 전송하지 마세요.

### sag

- 텍스트 음성 변환: 음성, 대상 스피커/방, 스트리밍 여부를 지정하세요.

로컬 도구 체인에 대해 어시스턴트가 알아야 할 내용을 자유롭게 추가하세요.
